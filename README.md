# 像素方块世界 (Voxel Block World)————mini mc

基于 Three.js 的 3D 像素风格方块世界探索游戏。原生 HTML + CSS + JavaScript (ES Module) 实现，无需构建步骤，支持桌面端（键鼠）与移动端（触控）。

世界中心矗立着一面用树叶方块搭建的 **"Coze" 文字立墙**，玩家将出生在墙前广场，周围是噪声生成的自然地形、树木与游荡的机器人。

## 功能特性

- 无限（按渲染距离动态加载）体素地形：Simplex 噪声 + FBM 生成高度图，自动铺草/泥土/沙/石，海平面水域
- 世界中心 "Coze" 文字立墙（9×9 像素位图字母，3 格厚树叶方块立墙）+ 环绕的草地广场
- 程序化生成纹理：Canvas 逐像素绘制 16×16 贴图并合并为图集，`NearestFilter` 保留像素风
- 第一人称控制：AABB 碰撞检测、重力与跳跃、DDA 射线拾取方块、放置/破坏
- NPC 机器人：ScoutBot（轻型，群体游荡）与 HeavyBot（重型，独行），随区块动态生成/回收
- 视野调节（`= / - / 0` 快捷键与 Ctrl+滚轮）、方块高亮、雾效遮蔽加载边界
- 移动端适配：虚拟摇杆 + 触控按钮、降低像素比、低功耗 WebGL、增量生成让步

| 项目 | 说明 |

## 操作说明

## 项目结构

```
index.html          # 入口页面：importmap、桌面端/移动端 UI 结构
styles/main.css     # HUD、开始画面、触控 UI、响应式布局
js/noise.js         # 带种子的 2D Simplex 噪声 + FBM 分形叠加
js/voxel.js         # 体素引擎核心：方块定义、纹理图集、Chunk/World、地形与文字立墙生成
js/animals.js       # 机器人实体系统：Robot 基类、ScoutBot/HeavyBot 模型与 AI、生成管理
```

### 模块说明

- **noise.js** — `SimplexNoise` 类：基于种子的 2D Simplex 噪声；`fbm()` 分形布朗运动叠加多频率噪声。
- **voxel.js** — `BlockType`（9 种：空气/草/泥土/石/沙/木/树叶/水/遗留的 COZE_CYAN）、`Chunk`（16×48×16 数据 + BufferGeometry 网格，仅渲染暴露面）、`World`（区块管理、噪声地形、树木生成、"Coze" 立墙与平地生成）。
- **animals.js** — `Robot` 基类（idle/wander 状态机、行走摆动动画、地面寻高）+ `ScoutBot`/`HeavyBot` 子类 + `AnimalManager`（桌面 5+3 只、移动端 2+1 只，Chunk 级生命周期）。
- **game.js** — `Player`（第一人称控制、AABB 碰撞、重力、DDA 射线）、`TouchController`、`BlockHighlight`、`Game`（渲染器/场景初始化、区块增量加载、双端事件、FOV 调节、游戏循环）。

## 性能优化

1. 面剔除：仅渲染暴露于空气的方块面
2. 区块合并网格：每区块一次 draw call
3. 渲染距离 4 区块（圆形范围），雾效隐藏加载边界
4. 增量加载：每帧最多生成 2 个区块，移动端每个区块让步一次主线程
5. 脏标记：仅方块变化时重建区块网格
6. 全空区块跳过网格构建
7. 移动端：像素比上限 1.2、`powerPreference: 'low-power'`、区块高度 48（地形最高约 40）

## 关键常量

| 常量 | 值 | 说明 |
|------|----|------|
| `CHUNK_SIZE` | 16 | 区块 XZ 尺寸 |
| `CHUNK_HEIGHT` | 48 | 区块高度 |
| `RENDER_DISTANCE` / `MOBILE_RENDER_DISTANCE` | 4 / 4 | 渲染距离（区块数） |
| `SEA_LEVEL` | 20 | 海平面高度 |
| `TEXT_GROUND_Y` | 18 | 立墙广场地面高度 |
| `TEXT_BASE_Y` | 19 | 立墙底部 Y |
| `TEXT_FLAT_RADIUS_X` / `_Z` | 22 / 10 | 广场 X/Z 方向半径 |

## 已知部分实现细节

- 玩家出生点为 `(5.4, -27, 22.6)`，位于世界底面之下，依靠 `game.js` 中的虚空保护（`y < -10` 时传送至 y=50）实现"天降"落至地面。
- `COZE_CYAN` 方块类型与纹理为早期"粉色文字墙"方案的遗留定义，当前文字墙使用树叶方块搭建。
